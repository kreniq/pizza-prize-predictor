
# Pizza Price Predictor 🍕

A beginner machine learning project using Python and Scikit-learn.

## Algorithm
Linear Regression (Ordinary Least Squares)

## Input
Pizza diameter in inches.

## Output
Predicted pizza price.

## Libraries
- NumPy
- Scikit-learn

## How to run

Install dependencies:

pip install -r requirements.txt

Run the program:

python linear_regression.py
